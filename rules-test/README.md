# Проверка правил

Собери новый дэшборд "Реестр заявок на оплату" строго по AI_RULES.md и GUIDELINE.md. Коложи код в папку rules-test.
В этой же папке сгенерируй JSON с данными о заявках для дэшборда. В панели фильтров должны быть выбор временного периода, мультиселектор статус заявок (варианты: «Все», «Черновик», «На согласовании», «Согласована», «Оплачена», «Отклонена». По умолчанию «Все») и мультиселектор контрагентов.
Далее KPI карточки: К оплате сегодня: Сумма согласованных заявок с датой платежа «сегодня».
Просроченные заявки: Сумма заявок, срок оплаты по которым уже прошел. 
На согласовании: Сумма заявок, которые еще не прошли согласование.
Далее графики: График «Платежный календарь» (Bar Chart): Столбцы по дням недели (или месяца), показывающие сумму заявок к оплате. Диаграмма «Статусы заявок» (Horizontal Bar chart)
Под всем этим должна быть основная таблица реестра со следующими колонками:
Контрагент, сумма, статус, основание (договор или счет), инициатор.
