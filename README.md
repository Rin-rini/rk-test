
## Структура проекта

| Путь | Назначение |
| --- | --- |
| `ui-kit/` | Токены, компоненты, графики, layout, форматирование |
| `ui-kit/stories/` | Истории Storybook |
| `dashboard/` | «Исполнение бюджета: план / факт» |
| `legacy-redo/` | «Движение денежных средств» |
| `rules-test/` | «Реестр заявок на оплату» |

## Запуск

```bash
npm install
```

Три дашборда — отдельные dev-серверы:

| Команда | Экран | Порт |
| --- | --- | --- |
| `npm run dev` | Исполнение бюджета | 5173 |
| `npm run dev:legacy` | Движение денежных средств | 5174 |
| `npm run dev:check` | Реестр заявок на оплату | 5175 |

Storybook (компоненты и графики kit):

```bash
npm run storybook
```

Порт **6006**.
