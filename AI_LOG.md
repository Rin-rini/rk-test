> **💬 Запрос к ИИ:**  
> 1. KPI-карточка:
   Пропсы: title, value, delta (число), deltaPercent, trend ('up' | 'down' | 'flat'), unit.
   Визуал: Крупное значение. Дельта и процент цветом. Иконка тренда.
> 2. Панель фильтров :
   Состоит из селектора диапазона дат, а также мультиселектора, которому можно передавать набор вариантов.
   Должна принимать массив конфигурации фильтров и отдавать единый объект панели
> 3. Таблица:
   Заголовки с кликабельной сортировкой (стрелки asc/desc).
   Поддержка форматирования ячеек (валюта, проценты).
   Скелетон-строки при загрузке.
> 4. Карточка графика:
   Заголовок, тело.
   Внутри — заглушка для интеграции с Recharts
> 5. Легенда:
   Принимает массив серий.
   Поддержка скрытия/показа серии по клику (визуально — приглушение цвета легенды).
> 6. Тултип:
   Для графиков: показывать значение и дату.

> Состояния (для всех компонентов данных) Каждый компонент, работающий с API (KPI, Table, ChartCard), должен уметь отрисовывать:
- Загрузка: Скелетоны (серые мерцающие блоки) вместо контента.
- Нет данных: Пустой стейт с иконкой, заголовком "Нет данных за выбранный период" и подзаголовком "Измените фильтры или проверьте источник".
- Ошибка: Блок с иконкой ошибки, текстом "Не удалось загрузить данные" и кнопкой "Повторить", которая триггерит колбэк onRetry.
